## Troubleshooting

### **"Install" Button Not Showing?**

**Solution 1:** Refresh the page
```
Press Ctrl+Shift+R (Windows) or Cmd+Shift+R (Mac)
```

**Solution 2:** Clear browser cache
- Chrome: Settings → Privacy → Clear browsing data
- Safari: Develop → Empty Web Storage
- Firefox: History → Clear Recent History

**Solution 3:** Make sure:
- You're using a supported browser (Chrome, Edge, Safari, Samsung Internet)
- You're not in incognito/private mode
- The app is being served over HTTPS (it is ✅)

**Solution 4:** Wait 30 seconds
- The app needs to register the service worker first
- Then the install prompt will appear

### **Can't Install on iPhone?**

Make sure:
1. iOS 11.3 or later
2. Using Safari (not Chrome)
3. Using a supported URL (https:// with valid manifest)

**If still not working:**
- Force close Safari
- Clear Safari cache
- Reopen and try again

## FAQ

**Q: Is my data private?**  
A: Yes! All data stays on your device until synced to the server. No third-party tracking.

**Q: Does it work offline?**  
A: Yes! It caches data and syncs when back online.

**Q: Can I uninstall it?**  
A: Yes, just like any app. Delete from home screen (iOS) or app drawer (Android).

**Q: Will I get notifications?**  
A: Yes! Notifications are enabled (if you allow permissions).

**Q: Does it use my phone storage?**  
A: Minimal — just cached data (~10-50MB depending on usage).

**Q: Can I update it manually?**  
A: It auto-updates. But you can force update by clearing browser cache.

## Still Having Issues?

Try these steps in order:

1. **Hard refresh:** Ctrl+Shift+R (or Cmd+Shift+R on Mac)
2. **Clear cache:** Browser settings → Clear browsing data
3. **Force close browser:** Close completely and reopen
4. **Check internet:** Make sure you have a good connection
5. **Try different browser:** If one doesn't work, try another

If still not working, the app requires:
- HTTPS (it has it ✅)
- Valid Web App Manifest (it has it ✅)
- Service Worker (it has it ✅)
- Supported browser (Chrome, Edge, Safari, etc.)
