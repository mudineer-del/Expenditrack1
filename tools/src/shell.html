How the costs are picked up

  • DRFD01/01 is always read as the contractor line — it is never counted again as DRFD01. Variants like DRFD-01 / 01 are matched too.
  • Any other sub-contract (DRFD01/02, /03 …) is listed in the notes but kept out of both columns.
  • Three sheet layouts are handled: a code per row (value taken from the Cost/Amount column), codes as column headers (column TOTAL row, else the column sum), and a code as a section heading (the section's TOTAL row).
  • Columns headed cumulative / to-date / quantity / rate are ignored, so "today" costs are not mixed with running totals.
  • The date comes from the sheet's own Date cell, else the file name, else the folder name, else the file's modified date — the source is shown for every row.
